# React + TypeScript + Vite
3Link es una aplicación web para guardar palabras junto con distintos filtros y organizarlas en forma de cartas. Permite agregar nuevas palabras, visualizar todas las existentes y seleccionar filtros para obtener 3 cartas aleatorias que coincidan con al menos uno de ellos. Está desarrollada con React y TypeScript en el frontend, y Spring Boot con PostgreSQL en el backend.
